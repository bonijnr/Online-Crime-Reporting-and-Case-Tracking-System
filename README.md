Online-Crime-Reporting-and-Case-Tracking-System

Project Description

The Online Crime Reporting and Case Tracking System is a web-based application designed to allow users to submit crime reports online and track the progress of their submitted cases using a unique reference number.

The system also provides a simple case management section where reports can be viewed and their statuses updated.

Features

- Submit crime reports online.
- Generate unique case reference numbers.
- Track submitted cases.
- View reported cases.
- Update case status.
- Responsive user interface.

Technologies Used

- HTML – Website structure.
- CSS – Website styling and layout.
- JavaScript – Functionality and interactivity.
- Local Storage – Saving demo reports in the browser.

How to Run the Project

1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open "index.html" in your browser.
4. You can also use the Live Server extension.

Project Limitations

This is a frontend demonstration project. Reports are stored in the browser's local storage and are not shared across devices. It does not include a backend or database.

Project Purpose

This project demonstrates how technology can be used to simplify crime reporting and improve the organization and tracking of reported cases.
